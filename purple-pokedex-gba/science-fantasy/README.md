# Science-fantasy Pokédex palette

This is a six-bank JASC-PAL variant for the existing 240 × 160 Pokédex background export. It keeps the original palette-bank structure and entry positions, shifts the dark field toward river indigo and teal, and moves the record panels toward parchment, bracken, and restrained resonance cyan. Entry 0 remains reserved in every bank.

The prototype build converts this palette into the GBA palette format and recolors the matching foreground assets. It is included in the successful **Reedwake Scientific Fantasy** BPS build. The patch also applies the Reedwake opening changes and a Bulbasaur Field Notes / Research / Delta prototype. The SVG in this folder is still a mockup/reference; the complete in-game interface and full species roster are not implemented.
